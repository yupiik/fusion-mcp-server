In one paragraph

MCP is JSON-RPC 2.0 and Fusion already generates a reflectionless JSON-RPC stack at build time, so this project is mostly wiring: the MCP methods are plain @JsonRpc methods, tools/call re-enters the standard handler, the tool descriptors are a projection of the generated OpenRPC document, and the only genuinely specific part is the transport

  • sessions, SSE and the routing of the client responses. See Design for the details.
